# AI 自动与手动额度

- `ai_auto`：后台 worker 发起的 AI 请求，每个账号每日 100 次。
- `ai_manual`：用户通过 API 操作发起的 AI 请求，每个账号每日 20 次。
- 两池独立计数、独立并发；各池全站每日保护上限默认 1000，每账号并发 2、全站并发 4。
- 按实际发起的 AI 请求计次，不是按钮点击次数。简要和详细摘要分别请求时分别计次；已发起的失败请求也计次，准入拒绝不计次。
- 按 UTC 零点重置，即北京时间每天 08:00。
- 老 `ai` 账本只保留历史，无法准确拆分的历史消耗不转扣新池。
- 通过 `TASK_AI_AUTO_*`、`TASK_AI_MANUAL_*` 配置；旧 `TASK_AI_*` 不再影响新池。API 与 worker 必须使用同一套配置。
- 后台监控和限流错误分别显示池名、限额原因、用量和可确定的重置时间。
