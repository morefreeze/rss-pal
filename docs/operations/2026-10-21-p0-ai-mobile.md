## 已修复

- API 与 worker 共用 PostgreSQL 总结租约，按文章互斥；正文与租约令牌共同校验写入，过期执行者无法覆盖新结果。请求超时6分钟、租约10分钟，进程中断后可恢复重试。
- 自动总结失败按1、2、4分钟指数退避，最高256分钟；预算不足时不早于额度恢复时间。筛选待处理文章时排除运行中和退避中的任务，避免最新失败文章反复占用名额。手动操作可主动重试失败任务。
- 拒绝空/空白模型输出，失败保留已有总结；拒绝无正文输入；保留图片正文的视觉总结路径。视觉调用预算不足或取消时直接保留错误类型，不再额外降级调用。
- 总结成功 JSON 与流完成帧均在数据库提交后发出。任务状态可在详情读取；持久化失败原因不记录内部地址、带密钥URL等原始provider错误。
- 前端将没有完成帧的连接结束视为中断；错误与完成互斥。文章切换、后续生成和状态查询使用请求身份校验，防止旧响应污染。刷新后显示已有生成状态并轮询，确认完成后清除旧连接警告。
- 阅读进度按文章保留未确认快照，网络失败自动重试，新滚动不会被旧确认清除。显式标记未读会等待在途写入并撤销旧重试；离页后的响应不会更新其他文章或组件。
- 返回文章列表恢复离开前已加载的分页及滚动位置，同时重新校验已加载窗口，反映取消收藏、隐藏和摘要变化；支持StrictMode重放。加载错误显示重试入口。
- 手机宽表格改为局部横向滚动，长链接与代码不撑宽页面；总结模板和生成按钮最小44px触控高度。
