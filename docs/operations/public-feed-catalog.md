# 人工公共推荐目录

管理员入口 `/admin/feed-catalog`。目录与个人订阅、探索候选表相互独立；添加条目不订阅、不公开个人文章。用户仍须预览并确认订阅。

- 草稿创建 → 检查 → 上架；上架会再次真实检查 RSS。
- 地址变更自动下架并撤销旧检查。并发编辑返回409，刷新后重试。
- 下架不消耗抓取额度；检查及上架受交互并发与抓取预算限制。
- RSS检查限时30秒、响应最多2MiB；公网安全DNS/重定向验证保持启用。
- 迁移046将原28项热门推荐复制为草稿；无个人feed变更。
- B站种子使用公共用户主页交由现有可信解析器转换；其他旧内部RSSHub种子改成公共rsshub.app地址，不放行内部主机。这些源可能被上游拒绝，检查失败保持草稿。

首次部署后在腾讯服务器 `/opt/rss-pal` 执行一次：

```sh
docker compose run --rm --no-deps api ./server --initialize-feed-catalog
```

仅检查带种子标记、revision=1、未检查且未上架的条目，最多28条、并发2、总时限20分钟。使用现有管理员的交互/抓取额度。已人工编辑或已检查的条目不重复处理；失败项由管理员页面重试。不会启动HTTP服务或个人订阅抓取。

验收：迁移前后个人feed计数/归属/暂停状态一致；已发布项均有真实成功检查时间；草稿不出现在用户热门推荐。不要用UPDATE时间戳或直接改published来跳过验证。
