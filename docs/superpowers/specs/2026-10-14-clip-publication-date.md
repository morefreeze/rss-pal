# 网摘发布日期

已确认范围：普通网页网摘、新采集及重新抓取读取原文发布日期；历史回填限定用户 1 在北京时间 2026-09-14 00:00 起采集的网摘，只补空值。对应有效分享快照只补 published_at，保留链接、正文及其他字段。无法访问或无法明确确认发布日期的文章保持为空。

## 实现边界

- 统一 Go 日期解析：明确的 publication meta、文章 JSON-LD datePublished、带 publication 语义的 time、微信公众号 publish_time。忽略更新时间、评论日期、正文中的任意日期及 URL 推测。
- 浏览器采集保留惰性的 JSON-LD 和微信日期元数据，后端在清理 HTML 前解析。正文清理仍移除脚本。
- 普通网摘新增保存 PublishedAt；重复采集和手动重抓只补 NULL，不覆盖已有日期。重抓沿用现有超时与事务保证。
- 运维 CLI 默认只读预览，必须明确 owner/since；应用时每条再次检查 owner、网摘类型、采集窗口及空值，事务内同时补相关有效分享的空日期。逐条报告成功、无日期、访问失败。
- 回填前保存该批文章及分享原始时间/快照；回填后核对数量、无范围外变化及原分享页可见日期。
