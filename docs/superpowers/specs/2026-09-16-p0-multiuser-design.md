# 公开注册 P0 加固设计

用户已明确要求记录 TODO 并修复 P0，本轮交付包含测试和腾讯部署。

1. 资源隔离：私有 PDF 图片要求资源绑定授权，禁止匿名枚举；公开分享仍只通过有效分享授权访问。订阅写操作只允许本人或管理公共订阅的管理员；共享读取不意味着共享写入。
2. 任务准入：PostgreSQL 原子预留额度与在途租约，跨进程共用，日额度按 UTC 日期；失败尝试计费，避免利用失败无限重试。过期租约释放并发但不退还日额度。数据库不可用时 fail closed。API 身份取认证上下文，不信任客户端 owner。
3. 默认额度（可配置）：每用户每日 AI 50、交互抓取/预览100、采集100、PDF10、订阅新增30；每用户同时昂贵任务2。全局 AI 每日1000、同时4；后台抓取和AI使用相同账本且按归属计量，共享源记系统配额。批量导入不得绕过额度。
4. 兴趣分析保持3/滚动24小时、100/滚动30天，原子锁定用户后计数+插入；只在提交成功后启动异步任务，回写使用独立 owner-scoped事务。
5. 不购买验证码套餐、不删除业务数据、不调用真实付费AI作测试。错误返回429（额度）或503（检查不可用），不泄漏凭据。
6. 验证：真实Postgres/RLS两用户、并发争抢、故障关闭、跨窗口及租约回收；现有前后端完整检查、浏览器关键流程、部署版本/资产/健康。
