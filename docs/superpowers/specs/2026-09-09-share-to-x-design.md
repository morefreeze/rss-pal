# 公开文章分享到 X 设计

日期：2026-09-09

## 目标

在无需登录的公开文章页 `/share/:token` 增加“分享到 X”入口。点击后在新标签页打开 X 的发帖编辑器，并预填完整可发布文案；用户只需检查内容并点击 Post。

本功能不会代替用户发布，不申请 X API 权限，也不新增后端接口。

## 入口与交互

- 入口放在公开阅读器的操作区，与“阅读原文”并列。
- 使用普通外链打开 X Web Intent，保留浏览器原生新标签页行为并避免弹窗拦截。
- 链接使用 `target="_blank"` 和 `rel="noopener noreferrer"`。
- 未登录 X 时由 X 自己承接登录；RSS Pal 不读取 X 账号状态。

## 预填文案

文案顺序固定为：

```text
文章标题

文章总结（按剩余空间截断）

公开分享链接
```

标题和公开分享链接必须保留。总结优先使用 `summary_brief`，为空时使用 `summary_detailed`；总结先转换为适合社交发布的单段纯文本，去掉 Markdown 标记并合并连续空白。

公开分享链接从当前页面的 `origin + pathname` 生成，不携带 query、hash 或原文章 URL，确保访客打开的仍是可撤销、可过期的 RSS Pal 分享快照。

## X 长度适配

按 X 的 280 加权字符上限计算，达到约 140 个中日韩字符的约束：

- 中日韩字符和 Emoji 按权重 2 计算。
- 普通拉丁字母、数字、空格和常用 ASCII 标点按权重 1 计算。
- 分享 URL 按固定权重 23 预留。
- 分隔换行计入总权重。
- 在保留标题、分隔和 URL 后，将全部剩余权重分配给总结。
- 总结被截断时添加 `…`，并保证添加省略号后仍不超过上限。
- 极端超长标题先截断标题；公开分享链接始终保留。

长度和截断逻辑放在纯函数工具中，不依赖 DOM，供单元测试直接覆盖。

## 异常与安全

- 缺少总结时只预填标题和分享链接。
- 非浏览器或当前地址不可用时不渲染失效的 X 链接。
- 所有参数使用 `URLSearchParams` 编码，不拼接未编码文本。
- 不把正文、私有 feed URL、用户身份、标签或阅读进度带入 X。

## 测试与验收

单元测试覆盖：

- 中文、英文、中英混排和 Emoji 的权重计算。
- 优先简短总结、详细总结回退和无总结。
- Markdown 转纯文本及空白合并。
- 长总结和极端长标题截断后不超过 280 权重。
- URL 固定权重和省略号边界。

组件测试覆盖：

- 公开页面显示“分享到 X”。
- 链接在新标签页打开 X Web Intent。
- 解码后的预填内容包含标题、尽可能多的总结和当前 `/share/:token` 链接。
- 不包含原文章 URL、私有数据、query 或 hash。

浏览器验收：从真实公开分享页点击入口，X 编辑器已填好文案，用户只剩点击 Post；返回 RSS Pal 后页面状态不变。
