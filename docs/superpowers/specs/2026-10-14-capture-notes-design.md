# 保存网页时记录随手记

用户已确认：一个自由输入框，并增加提示和便利，鼓励记录。插件保存按钮前常驻「随手记（选填）」，提示「一句话也好，留给未来的自己。」；辅助文案明确为什么收藏、在哪里发现、当下联想。三个可点击提示插入「我想保存，因为」「我是在……看到的：」「我想到可以用来」。选中网页文字可一键引用，Cmd/Ctrl+Enter 保存。空白仍可直接保存。

草稿按服务器、token 的不可逆摘要和网页 URL 隔离，使用 extension storage.local，不同步到云端；输入即保存、失败与关闭弹窗保留，仅服务器确认笔记保存后清理。保存时冻结本次输入并禁用编辑，避免晚到响应清理后续文字；避免跨账号与网页串稿。保存旧文章时随手记可独立成功，正文重复提示说明「随手记已保存」，后续覆盖不重复追加。输入上限 2000 字，展示计数。

HTML 与 PDF capture 接口接收可选 capture_note，响应 note_saved=true 才表示服务端支持且成功保存。旧服务器没有该字段时保留草稿并提示更新服务。新笔记追加到已有笔记，空白不会擦除，完全相同的末段视作重试不重复。重复提示也保存随手记，覆盖/新建正文时仍可选择新建。

每篇文章每个用户一个私人 capture_note 文本，独立于正文、编者说明、AI 摘要和公开分享。最大总长度 10000 字，不允许静默截断。数据库启用用户 RLS；所有请求先检查文章归属/可访问性，同事务存储；备份包含笔记。文章详情返回 article.capture_note 并在标题区域显示「我的随手记」，可编辑、清空，Ctrl/Cmd+Enter 保存，失败保留输入。网摘接口返回 capture_note，卡片显示单行预览。PATCH /api/articles/:id/note {capture_note:string} 返回 {capture_note:string}。页面编辑上限 10000 字。

范围为手动保存单篇 HTML/PDF；X 批量抓取和后台同步没有单篇想法语义，随手记区域明确用于当前网页的普通保存。

验证：插件 DOM 交互、草稿隔离与恢复、重复/失败/旧服务器、PDF、引用与快捷键；数据库持久化/追加/空值/越权/分享排除、HTTP 更新及 ETag；前端编辑/错误/预览；完整构建和相关回归。合并 master、推送和既定 Tencent Actions 部署，核对 revision、health、新插件下载与浏览器实际保存读取。
