# Public Article Share to X Implementation Plan

> **For agentic workers:** Choose the execution mode with the Execution Routing section below. Use superpowers:executing-plans for small or tightly coupled plans, and superpowers:subagent-driven-development for larger plans with independently reviewable tasks. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a public-reader action that opens X with a ready-to-post title, maximum available summary, and canonical RSS Pal share URL within X's weighted length limit.

**Architecture:** A DOM-independent `xShare` utility owns Markdown cleanup, grapheme-safe weighted truncation, URL weighting, and intent URL generation. `PublicArticleReader` derives the canonical `origin + pathname` share URL and renders a safe new-tab X intent anchor; no backend or authenticated API changes are required.

**Tech Stack:** React 18, TypeScript, URL/URLSearchParams, `Intl.Segmenter`, Vitest, Testing Library.

- [ ] **Step 3: Implement the pure composer**

Create this public surface:

```ts
export const X_MAX_WEIGHT = 280
export const X_URL_WEIGHT = 23

export type XPostInput = {
  title: string
  summaryBrief?: string
  summaryDetailed?: string
  shareURL: string
}

export function plainSocialText(markdown: string): string
export function xWeightedLength(text: string): number
export function truncateXText(text: string, maxWeight: number): string
export function buildXPostText(input: XPostInput): string
export function buildXIntentURL(postText: string): string
```

Implementation rules:

- Iterate `Intl.Segmenter(undefined, { granularity: 'grapheme' })` segments; weight an all-ASCII grapheme as 1 and any non-ASCII grapheme as 2.
- In `xWeightedLength`, scan `http:`/`https:` non-whitespace URLs and count each complete URL as 23 rather than counting its source characters.
- In `plainSocialText`, turn Markdown links and images into visible labels, remove fenced/inline code markers, headings, emphasis, quotes and list markers, remove bare URLs, and collapse whitespace to one space.
- Compose `title`, optional summary, and `shareURL` with blank lines. Reserve 23 for the share URL and count separators before allocating the summary budget.
- Preserve the URL under all inputs. If required content exceeds 280, truncate the title by complete grapheme and append `…`; omit the summary when it cannot fit with its separators.
- Build `https://x.com/intent/post` with `new URL()` and `url.searchParams.set('text', postText)`.

function currentPublicShareURL(): string | null {
  if (typeof window === 'undefined' || !window.location.pathname.startsWith('/share/')) return null

}
