RSS Pal 隐私政策

更新及生效日期：2026 年 10 月 29 日

RSS Pal 是以 RSS 订阅和阅读为主、提供稍后读与 AI 辅助功能的服务。本政策适用于 rss.morefreeze.top 的网页及手机浏览器使用场景，说明我们为提供这些功能如何处理数据。隐私问题、数据访问、导出或删除申请，请联系 morefreeze@gmail.com。

1. 账号与登录

使用邮箱验证码时，我们处理邮箱地址、验证码校验记录和发送时间，并使用 IP 的摘要进行发送频率限制。验证码有时效且只能使用一次；服务端保存其校验摘要。使用账号密码登录的既有账号保存用户名和密码哈希。

使用 Google 登录或绑定账号时，我们请求 openid、email、profile 权限，用于验证身份。当前实现将 Google 的账号标识和已验证邮箱与 RSS Pal 账号关联，不保存 Google 密码，也不将 Google 返回的访问令牌作为长期访问凭证保存。当前不保存 Google 头像和姓名，不读取 Gmail、通讯录或 Google Drive 数据。Google 身份数据用于登录及账号关联，不用于 AI 内容处理。

使用 GitHub 登录或绑定账号时，我们通过 GitHub 授权及用户身份接口获取稳定的用户 ID，用于登录和账号关联。不申请私有邮箱或仓库权限，不保存 GitHub 密码、头像或长期访问令牌，也不将 GitHub 身份数据用于 AI 内容处理。

使用 QQ 登录或绑定账号时，会向腾讯 QQ 互联请求基本身份授权（get_user_info）。当前实现通过令牌及 OpenID 接口校验应用标识和用户 OpenID，再调用 get_user_info 读取并保存 QQ 昵称和头像链接，用于账号展示。已有自定义昵称会保留，未设置时可使用 QQ 昵称显示。浏览器加载 QQ 头像时会向腾讯头像服务发起请求，因此腾讯会接收到加载所需的网络信息；我们不发送 RSS Pal 页面地址作为头像请求的 Referrer。不保存接口返回的性别、地区、会员等其他资料，不获取或保存 QQ 密码、聊天记录、好友关系或长期访问令牌，也不将 QQ 昵称、头像或登录身份用于 AI 内容处理。

2. 订阅、阅读与保存的内容

我们保存你添加的订阅源、分组、阅读及收藏状态、稍后读内容、笔记、偏好设置，以及相应的文章链接、正文、图片等内容，用于跨设备阅读、同步、检索和推荐。通过浏览器扩展、分享或网页保存功能提交的内容也会进入该处理流程。访问原文、加载远程图片或媒体时，相应网站可能接收你的网络请求信息；由服务器代为抓取时，请求会从服务器发出。

3. AI 功能

为生成摘要、翻译、分类、问答和阅读建议，服务会把相关的文章标题、正文、图片或其他内容，连同必要的指令，发送到所配置的第三方模型服务。兴趣分析和个性化推荐还可能使用阅读过的文章标题、阅读标记、兴趣主题、关键词和候选文章信息。部分内容处理会在后台执行。生成结果会保存以供阅读和复用。

模型服务由运营配置，相关请求可能经过第三方模型 API 或网关，其处理地点和保留规则取决于实际提供方。请避免向保存、笔记或 AI 功能提交不希望交由这些服务处理的敏感信息；如需了解当前提供方，可通过上述邮箱联系我们。

你在设置中填写的个人 API Key 仅保存于当前浏览器，按本站账号分别存储。默认保存在当前标签页会话；选择“在此设备记住 Key”后保存在浏览器本地存储，直到主动清除。个人 Key 不上传本站，不跨设备同步，也不进入本站数据备份。先前保存在服务器的个人 Key 已停用并清除；这不代表供应商侧凭证已撤销，也不保证历史独立备份已清理。

个人 Key 仅在你主动测试连通性、生成文章总结或润色模板时，由浏览器直接发送给你配置的 HTTPS 模型接口；文章总结结果会同步到本站。保存配置、打开文章不会触发个人 Key 调用。浏览器直连需要供应商支持 CORS；本站不提供携带个人 Key 的服务器代理。连通性测试也会产生少量模型请求，可能收费。浏览器扩展、共享设备或网站脚本漏洞仍可能使本地 Key 泄漏，请使用专用、限额凭证。系统 AI 及其后台任务独立运行，不使用你的本地 Key。

4. 验证码、邮件及运行服务

公开邮箱注册使用腾讯云验证码进行人机验证。验证组件会与腾讯云通信，由其处理完成验证所需的 IP、浏览器及设备环境等信息。邮箱验证码由腾讯云邮件推送（SES）投递，涉及收件邮箱、验证码邮件内容和投递状态。可参阅 腾讯云隐私声明。

当前服务运行在腾讯云基础设施上，账号和阅读数据保存在服务端数据库及相关文件存储中。运行日志可能包含请求路径、时间、错误及必要的网络信息，用于排障、防滥用和安全维护。模型及邮件等第三方服务仅在提供对应功能时参与数据处理。

5. 浏览器存储与会话

浏览器本地存储保存登录令牌、账号信息、部分偏好及文章详情缓存，会话存储用于阅读状态和列表位置等体验。登录流程也可能使用 Cookie 维护验证状态。选择“记住此设备”时会使用可续期的会话凭证；相关登录界面标明最长 90 天。退出登录会清理当前浏览器中的登录凭证，但不一定清除已缓存的文章内容。在共享设备上使用后请退出登录，并通过浏览器清除本站数据。

6. 分享与公开访问

你主动创建的文章分享链接可被持有链接的人访问，并可能被转发。请在分享前检查所选内容；不要通过分享功能公开私人笔记或敏感内容。普通账号中的订阅和阅读记录并不因此自动成为公开分享内容。

7. 保存、安全与账号数据请求

我们在提供账号、同步和阅读服务所需期间保存相关数据，并使用访问控制、加密传输等措施保护数据。运行维护可能产生备份；备份及日志的清理与主数据库中的删除可能存在时间差。没有任何网络服务能保证绝对安全。

你可以在产品中管理订阅、保存内容及可用的账号设置。如需访问、导出或删除账号及关联数据，请联系 morefreeze@gmail.com，说明请求和对应账号。已绑定邮箱的账号请优先使用该邮箱联系；未绑定邮箱的账号，我们会通过已绑定的登录身份等方式核验账号归属，再回复处理方式。当前不提供统一的自助删除账号入口。你也可以在 Google 或 GitHub 账号的第三方应用设置中撤销授权；撤销授权不会自动删除已保存在 RSS Pal 的账号和阅读数据，删除仍需提出申请。

8. 政策更新与联系

功能或数据处理方式变化时，我们会更新本页面及生效日期。关于本政策或个人数据处理的任何问题，请联系 morefreeze@gmail.com。
